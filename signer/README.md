# 42avater-signer（ミントの署名サーバー）

メーカーの「CAW NAMEで無料ミント」で使うサーバーです。Cloudflare Worker と D1 で動きます（42GRAM のほかのサーバーと同じ形）。

## していること

ミントの申し込み（`POST /sign`）を受けると、次をすべて確かめてから、コントラクトの `mint()` に渡す署名（EIP-712）を返します。

1. **本人確認**：申し込みは、ミントするウォレット自身が MetaMask で署名したもの（無料、取引ではない）。10分より古いものは受け付けない。
2. **デザインのルール**：送られてくるのはデザインの番号（DNA）だけ。トークンに刻む中身は、このサーバーがメーカーと同じエンジンで作り直す。ルールに合わない組み合わせは断る。
3. **CAW NAME**：そのウォレットが持ち主であること、まだミントに使われていないこと（チェーンで確かめる）。
4. **見た目**：同じ見た目がまだミントされていないこと。
5. **コントラクトの状態**：ミントが開いていて締め切られていないこと、上限に達していないこと、このサーバーの鍵がコントラクトの署名者と同じであること。
6. **横取り対策**：署名を渡した見た目は、署名の期限（15分）まで、その人だけに予約する。ほかの人には同じ見た目の署名を出さない。予約は CAW NAME 1つにつき1つの見た目まで（別のデザインに変えると前の予約は外れる）。

秘密鍵は Cloudflare のシークレット（`SIGNER_KEY`）にだけ置き、ファイルやリポジトリには書きません。

## 置き方（あなたのパソコンで）

必要なもの：Node.js 22 以上、Cloudflare のアカウント（42GRAM と同じ）。

1. **署名者のウォレットを作る**：送り役と同じリカバリーフレーズの別アカウントでよい。残高は入れない。リカバリーフレーズは紙などに控える。
2. **コントラクトを置く**：配置ページで、署名者の欄にこのウォレットのアドレスを入れる。
3. **サーバーを置く**（このフォルダーで）：

   ```sh
   npm install
   npx wrangler login
   npx wrangler d1 create 42avater-signer       # 表示された database_id を wrangler.toml に書く
   # wrangler.toml の AVATARS にアバターのコントラクトのアドレスを書く
   npx wrangler d1 execute 42avater-signer --remote --file schema.sql
   npx wrangler secret put SIGNER_KEY           # 署名者のアカウントの秘密鍵を貼る（MetaMask の「アカウントの詳細」→「秘密鍵を表示」）
   npx wrangler deploy
   ```

4. **確かめる**：表示されたアドレス（`https://42avater-signer.<あなたのサブドメイン>.workers.dev/`）を開くと、`signer` に署名者のアドレスが出る。コントラクトの `signer()` と同じであること。
5. **メーカーに設定する**：Cloudflare Pages（`42avater`）の環境変数に `MAKER_SIGNER_URL`（上のアドレス）、`MAKER_CHAIN_RPC`、`MAKER_CHAIN_AVATARS`、`MAKER_CHAIN_ITEMS` を入れて、もう一度公開する。

## 鍵を変える・ミントを締め切る

- **鍵を変える**：新しい署名者のアカウントを作り、今の署名者のアカウントでコントラクトの `setSigner(新しいアドレス)` を送る。そのあと `npx wrangler secret put SIGNER_KEY` で新しい鍵に入れ替える。
- **締め切る**：署名者のアカウントで `closeMinting()` を送る。元に戻せません。サーバーは「ミントは締め切られました」と答えるようになります。

## テスト

```sh
npm install
npm test                       # 偽のチェーンと SQLite で、上の確認と横取り対策を試す
```

手元のチェーン（Anvil）で通しテストをするときは `test/dev-server.mjs` で動かせます（鍵は環境変数で渡す。本番には使わない）。
