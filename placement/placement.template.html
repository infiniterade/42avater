42gAvaterMaker 配置ページ（42 Chain）

このページは鍵を持ちません。送信はすべて MetaMask で1つずつ承認します。「済み」はいつもチェーンから読み直します。未監査の実験版です。

1. つなぐ

まだつないでいません。

2. 配置する（デプロイ）

前に配置したことがあれば、アドレスを入れて「チェーンから読み直す」を押すと、続きから進められます。

3. ローンチ後の設定（CAW NAME とローンチ記念）

CAW NAME の設定は1回だけ・変更できません。テスト用の CAW NFT を設定したこの配置は、本番には使えません（本番は別に配置します）。

4. 予行演習ミント

CAW NAME の持ち主のウォレットで行います。署名者のウォレットで署名（MetaMask の署名）→ ミントの送信、の順です。デザインは 42gAvaterMaker でコピーした DNA を貼るか、ランダムで。

5. 記録

配置したアドレスと取引です。42GRAM の設定やメーカーの CHAIN に使います。
